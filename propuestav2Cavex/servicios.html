Tipos de servicio

Soluciones para cada necesidad de traslado.

La vista está pensada para comunicar claramente qué ofrece CAVEX antes de que el usuario solicite un viaje desde la aplicación o el sitio web.

01

Traslado médico

Para citas médicas, terapias, hospitales, clínicas o consultas programadas.
  • Ideal para adultos mayores
  • Viajes con destino sensible
  • Mayor control para familiares

02

Viaje rápido

Para traslados sencillos donde el usuario necesita llegar pronto a un destino.
  • Solicitud directa
  • Ruta clara
  • Destino registrado

03

Chofer por horas

Para usuarios que requieren disponibilidad del conductor durante un periodo.
  • Actividades múltiples
  • Mayor flexibilidad
  • Tiempo previamente definido

04

Viaje familiar o grupal

Para traslados donde el pasajero viaja acompañado o se requiere más espacio.
  • Acompañantes
  • Mayor comodidad
  • Apoyo familiar

05

Viaje programado

Reserva un traslado con anticipación, definiendo fecha, hora, origen, destino, vehículo y tipo de recorrido.
  • Perfecto para citas importantes
  • Permite planear ida o regreso
  • Reduce improvisación y retrasos

Proceso del servicio

De la solicitud al destino, todo queda organizado.

La experiencia se estructura por pasos para que el usuario sepa qué está solicitando, quién viaja, hacia dónde va y cómo se dará seguimiento.
01

Selecciona el servicio

El usuario elige si necesita traslado médico, rápido, familiar, programado o chofer por horas.

02

Agrega los datos del viaje

Se define pasajero, origen, destino, fecha, hora y tipo de vehículo necesario.

03

Confirma y da seguimiento

El viaje queda registrado y el usuario puede recibir información del conductor y el recorrido.
